# 과제 — 증강 3종 만들기

**코드는 안 짜도 된다.** 세 개 모두 지금 있는 모듈 조합만으로 만들 수 있게 미리 확인해뒀다.
막히면 시스템이 아니라 조립이 잘못된 것이니 아래 "막혔을 때" 를 먼저 볼 것.

만들 것: **Iteration · C · Linear Search**

셋을 고른 이유는 서로 다른 걸 익히게 하려는 것이다.

```
Iteration       장전식 트리거 — 새로 들어온 BurstTrigger 를 처음 쓴다
C               연쇄 + 탐색풀 연동 — Bash 를 열어보면 절반은 답이 있다
Linear Search   직선 판정 + 표식 — DFS · BFS 가 선례다
```

---

## 1. 만들 증강

### Iteration (분류: 코드)

> 쿨타임마다 `" i "` 투사체를 **반복 횟수만큼 연속 발사**한다.
> 발사는 기본 사거리 내 **최근접** 대상을 향한다.
> **반복 횟수를 모두 소진하면 쿨타임이 시작된다.**

핵심은 **"탕-탕-탕-탕"** 이다. 한 번에 여러 발을 뿌리는 산탄이 아니라, 간격을 두고 연달아 쏘는 연사다.
발마다 그 순간의 최근접을 다시 겨눈다.

> 📄 `GUIDE_BurstTrigger.md` 를 먼저 읽을 것. 이 증강만 선례가 없어서 가이드를 따로 써뒀다.

### C (분류: 언어)

> 탐색 대상 중 **최근접**을 포인팅 목표로 지정한다.
> 화살표 모양의 **관통형** 포인터 투사체를 날린다.
> 지나가는 대상들에게 피해를 주고, 레벨에 따라 **다음 포인팅 목표로 연쇄**한다.
> 탐색 대상이 없으면 최근접을 쓴다.

핵심은 **관통 + 연쇄**다. Bash 도 연쇄를 쓰는데 그쪽은 한 명씩 튕겨 나가고, C 는 **한 줄을 꿰뚫고** 다음 줄로 넘어간다.

> 기획서의 *"주소를 노출시켜 방어력 감소"* 는 **이번에 빼고 만든다.** 적에게 방어력 개념이 아직 없다.
> 나중에 내부 증강 `C:free()` 로 붙일 자리다.

### Linear Search (분류: 탐색)

> 화면의 임의 공간에서 가로나 세로 방향으로 **스캔 형태의 직선 파동**을 긋는다.
> 적중한 적들을 **수량만큼만** 탐색(표식)한다.

핵심은 **직선 + 개수 제한**이다. 피해를 주는 증강이 아니라 **표식을 까는 증강**이다 —
다른 증강이 그 표식 위에 추가 피해를 얹는다. DFS · BFS 와 같은 역할이다.

## 2. 만드는 법

```
Project 창 우클릭 → Create → CoD → Augment
Data/Augment_Data/ 에 저장
```

인스펙터 위에서부터 채운다.

| 칸 | 넣을 것 |
|---|---|
| `Id` | 시트의 id 와 **정확히** 같게. `ITERATION` · `C` · `LINEAR_SEARCH` |
| `Display Name` | 화면에 뜰 이름 |
| `Category` | 코드 · 언어 · 탐색 |
| `Icon` | `Art/icons/` 에서 고를 것. 500장 넘게 있다 |
| `Description Template` | 카드에 뜰 설명. 아래 참고 |
| `Level Stats` | 레벨별 수치. 아래 참고 |
| 모듈 조립 | 트리거 → 타겟팅 → 전달 → 효과 |

### 설명문 토큰

`{damage}` 처럼 적으면 실제 수치로 바뀐다. 카드가 레벨업 전후를 화살표로 보여준다.

```
연속 발사 수: {count}
발당 피해: {damage}
쿨타임: {cooldown}초
```

`{effectDamage:%}` 는 30% 처럼, `{damage:0}` 은 소수점 없이 나온다.

## 3. 쓸 수 있는 재료

**① 발동 조건 (Trigger)** — 하나만 고른다

```
CooldownTrigger    일정 주기마다
BurstTrigger       장전 후 연달아 · 다 쏘면 쿨타임
SearchTrigger      쿨타임이 찬 뒤 다음 탐색에 얹혀서
```

**② 목표 대상 (Targeting)** — 하나만 고른다

```
적을 고른다     Nearest(1체) · Random(N체) · AllInRange(범위 안 전부)
                SearchPool(표식 붙은 적) · TreeFrontier(트리 말단)
좌표를 찍는다   OwnerPoint(내 자리) · DirectionPoint(향한 앞) · RandomPoint(임의 공간)
```

**③ 전달 방식 (Delivery)** — 여러 개 가능

```
날아간다     Projectile(겨눔) · Radial(각도로 퍼짐)
즉시 닿는다  Instant(대상에게) · Area(원·부채꼴) · Line(직선 레이저)
```

`Projectile` 안에는 `Pierce`(관통) · `Homing`(유도) · `MultiShot`(여러 발) 옵션이 있다.

**④ 효과 (Effect)** — 여러 개 가능

```
Damage       피해
Search       표식을 깐다 (탐색 증강의 핵심)
Chain        다음 대상으로 연쇄
Link         대상들을 간선으로 잇는다
Knockback    밀거나 당긴다
Status       둔화 · 지속 피해
SubPipeline  적중한 자리에서 다른 파이프라인 한 번
Vfx · Sfx · Log   연출
```

## 5. 레벨 수치

시트에 채운다. **한 행이 한 레벨이다.**

```
id              레벨  피해량  효과피해  쿨타임  사거리  효과범위  속도  지속시간  수량  관통력  깊이
ITERATION        1     8      0        3.0     7      0        14    0        4     0      0
ITERATION        2     9      0        2.9     7      0        14    0        4     0      0
```

빈 칸은 0이다. 안 쓰는 칸은 비워두면 된다.

채운 뒤 `CoD → 증강 시트 가져오기` 로 CSV 를 불러온다. **계산을 안 하므로 적은 값이 그대로 들어간다** —
3레벨마다 확 오르는 곡선을 원하면 시트에 그렇게 적으면 된다.

## 6. 완료 기준

아래가 전부 되면 끝난 것이다.

```
□ 플레이에서 실제로 발동한다
□ 레벨업하면 수치가 오른다 (카드에 "12 → 15" 처럼 화살표가 뜬다)
□ 카드 설명이 실제 수치와 맞는다
□ 콘솔에 경고가 없다
□ AugmentPool 에셋에 넣어서 선택지에 뜬다
```

**Iteration 추가 확인**

```
□ 한 번에 우수수 나가지 않고 탕-탕-탕 간격을 두고 나간다
□ 다 쏜 뒤에 쿨타임이 시작된다 (쏘는 중에는 쿨이 안 찬다)
□ HUD 아이콘 게이지가 탄창처럼 줄었다 다시 찬다
```

**C 추가 확인**

```
□ 투사체가 한 명에서 안 멈추고 뚫고 지나간다
□ 표식이 붙은 적이 있으면 그쪽을 먼저 겨냥한다
□ 레벨이 오르면 연쇄가 길어진다
```

**Linear Search 추가 확인**

```
□ 직선 위의 적들에게 표식이 붙는다
□ 표식 수가 시트의 수량을 넘지 않는다
□ 다른 탐색 증강(DFS 등)과 같이 들면 표식이 겹쳐 보인다
```

## 7. 지켜야 할 것

### 🔴 모듈 칸에 숫자를 직접 박지 말 것

`Scalable` 칸(값 · 배수)은 **값을 0으로 두면 시트를 따라간다.** 여기에 숫자를 박으면
시트를 아무리 고쳐도 안 변한다.

```
값 0  · 배수 1      ← 시트 그대로.  기본은 이것
값 0  · 배수 1.5    ← 시트의 1.5배
값 12 · 배수 1      ← 고정 12.  레벨업해도 안 변함  ← 꼭 필요할 때만
```

> 지금 기존 증강 몇 개가 이걸 어겨서 시트로 밸런싱이 안 되는 상태다. 새로 만드는 건 지키자.

### 프리팹은 스스로 사라져야 한다

투사체 · 이펙트는 풀에서 재사용된다. **`Destroy` 를 쓰면 안 된다.**

```
파티클      Particle System → Stop Action 을 Disable 로  (Looping 은 꺼야 함)
스프라이트  FxAutoDespawn 컴포넌트를 붙인다
```

### 뿌리 증강에는 확장 자리를 하나 남길 것

나중에 내부 증강(`Iteration:for` 같은 것)이 꽂힐 자리다.

```
Effects 목록 맨 뒤에  ExtensionEffect  하나
  Slot   자리 이름 (예: hit · final)
```

지금은 아무 일도 안 한다. 안 남기면 나중에 뿌리를 다시 뜯어야 한다.

## 8. 막혔을 때

**먼저 해볼 것**

```
1. 비슷한 기존 증강을 열어서 비교한다        ← 대부분 여기서 풀린다
2. 콘솔 경고를 읽는다 — 모듈이 왜 안 도는지 대부분 적혀 있다
3. 모듈 칸에 마우스를 올려 툴팁을 읽는다
```

**물어봐야 하는 것**

```
· 모듈 조합으로 아무리 해도 기획의 핵심이 표현이 안 될 때
  → 새 모듈이 필요한 것이므로 혼자 우회하지 말고 말할 것.
    우회해서 만들면 "비슷하지만 다른 증강"이 된다

· 기존 모듈의 동작이 툴팁과 달라 보일 때
  → 버그일 수 있다
```

**우회하면 안 되는 이유** — 기획의 핵심을 바꿔서 맞추면 나중에 되돌리기가 훨씬 비싸다.
`Greedy` 를 이번 과제에서 뺀 것도 같은 이유다(우선순위 타겟팅이 없어서 유도 미사일이 돼버린다).
